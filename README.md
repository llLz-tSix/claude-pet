# Claude pet

Маленький пиксельный питомец на рабочем столе для [Claude](https://claude.ai) — Windows и macOS.
Сам появляется, когда открыт Claude, и показывает, что тот делает: работает, ждёт тебя или закончил.
Клик по питомцу возвращает в чат.

> Неофициальный фанатский проект, не связан с Anthropic.

| Claude… | Питомец |
| --- | --- |
| ничего не делает | дышит, моргает, оглядывается; иногда машет, потягивается, подпрыгивает, жонглирует руками, пританцовывает; через 3 минуты засыпает |
| работает | сидит у ноутбука и стучит по клавишам |
| ждёт тебя | руки по очереди взлетают, над головой `!` (разрешение), `?` (вопрос) или лист (план) |
| закончил | прыгает и держит над головой галочку обеими руками |

Наведи мышь — радуется, кликни — сердечко и переход в Claude, можно перетащить в любое место экрана.
Правый клик — меню: «Открыть Claude», «Спрятать», «Выход».

## Установка

### Windows
Скачай репозиторий (Code → Download ZIP), распакуй и дважды щёлкни **`Start-Claude-Pet.bat`**.
Node.js не нужен: при первом запуске скрипт сам скачает движок Electron (~110 МБ).

### macOS
Нужен [Node.js](https://nodejs.org). Скачай репозиторий и дважды щёлкни **`Start-Claude-Pet.command`**
(если macOS не даёт открыть — правый клик → «Открыть»). Или в терминале:

```bash
npm install && npm start
```

После первого запуска питомец сам включает автозапуск вместе с системой и ждёт в фоне (значок возле часов / в строке
меню), пока не откроешь Claude.

## Как он узнаёт, что делает Claude
- **Claude Code** (вкладка Code в приложении и терминал) — питомец сам добавляет свои хуки в `~/.claude/settings.json`.
  Они сообщают о каждом шаге всех сессий, даже тех, что сейчас не на экране. Чужие хуки не трогаются.
- **Обычный чат в приложении Claude** — на Windows питомец читает кнопки «Остановить/Stop» и «Разрешить/Allow»
  в окне через UI Automation. На macOS так нельзя: там он видит только, открыто ли приложение.
- **claude.ai в браузере** (по желанию) — расширение из папки `extension`: открой `chrome://extensions`
  (или `edge://`, `opera://`), включи «Режим разработчика» → «Загрузить распакованное» → папка `extension`.

Всё общение идёт только через `127.0.0.1:47800` на твоём компьютере.

## Настройки
Файл `config.json` в папке данных (`%APPDATA%\claude-pet` на Windows, `~/Library/Application Support/claude-pet`
на macOS):

| ключ | что делает |
| --- | --- |
| `size` | размер, по умолчанию `0.8` |
| `followClaude` | `false` — показываться всегда, а не только вместе с Claude |
| `notify` | уведомления, когда Claude закончил долгий ответ или ждёт разрешения |
| `autostart` | запуск вместе с системой |
| `hooks` | `false` — убрать хуки из Claude Code |
| `stopWords`, `allowWords` | доп. названия кнопок «стоп» и «разрешить» в окне Claude, через `\|` |

Журнал — `pet.log` в той же папке.

## Для разработки
- `render.js` — рисует питомца по клеткам: туловище, ноги и руки-квадратики не меняют форму, позы считаются из времени.
- `tools/preview.html` — раскадровка всех сценок; `npm run preview` сохраняет её в `preview.png`.
- `main.js` — окно, меню, появление вместе с Claude; `hooks.js` — хуки Claude Code; `uia.js` — окно приложения;
  `browser.js` — локальный сервер для хуков и расширения.
